# Desafio 17 — Classe Produto e Etiqueta de Preço

## Descrição

Crie uma classe "Produto", onde seja possível cadastrar nome e preço do produto. 
Crie também um método que mostre uma etiqueta de preço desse produto.

## Instruções de setup

1. Clone ou baixe o repositório.
2. Acesse a pasta do desafio 17.
3. Execute o arquivo principal da solução.
4. Verifique se a etiqueta de preço está sendo exibida corretamente.

"""
