# Desafio 22 — Classe Controle Remoto

## Descrição

Crie uma classe `ControleRemoto` que simule o funcionamento de um controle simples. O controle deve permitir ligar e desligar, trocar canais para frente e para trás, e aumentar ou diminuir o volume.

## Instruções de setup

1. Clone ou baixe o repositório.
2. Acesse a pasta do desafio 22.
3. Execute o arquivo principal da solução.
4. Teste todos os botões simulados do controle.

```bash
python desafio022.py
```

## Critérios de aceitação

- [x] Existe uma classe `ControleRemoto`.
- [x] O controle pode ligar e desligar a TV.
- [x] O controle pode avançar e voltar canais.
- [x] O controle pode aumentar e diminuir o volume.
- [x] O canal não ultrapassa os limites definidos.
- [x] O volume não ultrapassa os limites definidos.
- [x] O botão de ligar/desligar funciona como alternância.
- [x] A execução mostra a TV e o estado atual do controle.
