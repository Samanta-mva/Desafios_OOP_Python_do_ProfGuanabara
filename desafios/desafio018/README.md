# Desafio 18 — Classe Churrasco e Cálculos

## Descrição

Crie uma classe `Churrasco`, onde seja possível informar quantas pessoas vão participar do churrasco. 
Ao final, o programa deve mostrar quanto de carne deve ser comprado, o custo total do churrasco e o preço por pessoa.

Considere o consumo padrão de 400 g de carne por pessoa e o preço de R$ 82,40 por quilo.

## Instruções de setup

1. Clone ou baixe o repositório.
2. Acesse a pasta do desafio 18.
3. Execute o arquivo principal da solução.
4. Verifique se os cálculos estão corretos.

```bash
python desafio018.py
```

## Critérios de aceitação

- [x] Existe uma classe `Churrasco`.
- [x] A classe permite informar título e quantidade de pessoas.
- [x] O método de análise calcula a quantidade de carne necessária.
- [x] O método de análise calcula o custo total.
- [x] O método de análise calcula o preço por pessoa.
- [x] Os valores exibidos batem com a regra de 400 g por pessoa.
- [x] A saída está formatada de forma clara.
